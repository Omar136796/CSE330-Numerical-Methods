# CSE330 – Numerical Methods (BRAC University)

Lab assignments from CSE330, BRAC University's numerical methods course,
implemented in Python with NumPy and Matplotlib. Covers polynomial
interpolation, numerical differentiation, root finding, and solving
linear systems. All work was done in Google Colab, and each notebook
includes its output and plots.

## Labs

| Lab | Topic | What's inside | Notebook |
|-----|-------|---------------|----------|
| 01 | Introduction to Python | Python, NumPy, and pandas basics | [Lab01](Lab01_Introduction_to_Python.ipynb) |
| 02 | Polynomial interpolation | Polynomial class, interpolation using the matrix method | [Lab02](Lab02_Polynomial_Interpolation.ipynb) |
| 03 | Lagrange interpolation | Lagrange form of the interpolating polynomial | [Lab03](Lab03_Lagrange_Interpolation.ipynb) |
| 04 | Newton's divided difference | Divided-difference table and Newton form interpolation | [Lab04](Lab04_Newtons_Divided_Difference.ipynb) |
| 05 | Numerical differentiation | Forward, backward, and central differences; error analysis; Richardson extrapolation | [Lab05](Lab05_Differentiation_and_Richardson_Extrapolation.ipynb) |
| 06 | Nonlinear equations | Bisection method and fixed-point iteration | [Lab06](Lab06_Nonlinear_Equations.ipynb) |
| 07 | Linear systems | Inverse-matrix method and Gaussian elimination | [Lab07](Lab07_Linear_Systems.ipynb) |
| Exam | Lab exam | Lab exam tasks | [Lab_Exam](Lab_Exam.ipynb) |
